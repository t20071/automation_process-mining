# data/

Sample input for experimentation. Everything else written here at runtime is gitignored.

| File | What it is |
|---|---|
| `event_logs.csv` | ~8.5k events / 2,000 synthetic expense-reimbursement cases, generated by `process_agent.generators.log_generator` (seed 42). Upload it in the app or use it in notebooks. |

## Schema

| Column | Required | Description |
|---|---|---|
| `case_id` | yes | Identifier shared by all events of one case |
| `activity` | yes | Step name, e.g. `manager_approval` |
| `timestamp` | yes | Event start time (any format pandas can parse) |
| `duration_seconds` | no | Time spent in the step. Derived from the next event's timestamp if absent |
| `variant` | no | Path label, e.g. `happy_path` |
| `amount` | no | Claim value |
| `submitter_id` | no | Who raised the case |

Column names are auto-detected (`Case ID`, `Task`, `Start Time`, `Elapsed`, … all work).
Regenerate the file with:

```bash
python -m process_agent.generators.log_generator
```
